# Mona Leafah · Mona’s Media

I write, design, and build small tools for publishing and research.

On Mona’s Media, I share finished work, explain how I made it, and offer help with content and distribution.

## Working systems

**[The Pin Multiplier](https://github.com/MonaLeafah/pin-multiplier)** turns one article brief into seven editable pin concepts, with text graphics, human review, plan dates, and a complete PNG/SVG/CSV/JSON packet. Its fictional demo runs locally without an account or API key.

**[The Signal Desk](https://github.com/MonaLeafah/signal-desk)** checks public repositories, compares saved snapshots, and exports a briefing with your notes and source links. [Try the research desk](https://monaleafah.github.io/signal-desk/).

The public projects use original code and clearly labeled examples. Employer-associated implementations and client material stay private.
